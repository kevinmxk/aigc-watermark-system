# Web 前端使用说明

## 快速启动

### Windows
```bash
双击 start_web.bat
```

### Linux/Mac
```bash
bash start_web.sh
```

### 手动启动
```bash
pip install streamlit
streamlit run web_ui.py
```

启动后访问: http://localhost:8501

## 功能说明

### 1. 生成页面
- 输入文本提示词
- 设置用户ID
- 选择运行模式（阶段管理器/传统方式）
- 点击生成按钮
- 下载生成的图像

### 2. 批量生成
- 输入多个提示词（每行一个）
- 设置用户ID前缀
- 自动按序生成多张图像

### 3. 水印检测
- 上传待检测图像
- 系统自动检测三层水印
- 显示检测结果

### 4. 系统架构
- 展示三层水印架构
- Tree-Ring、DAAM、StegaStamp 说明

## 注意事项

1. **环境准备**: 确保三个 conda 环境已正确安装
2. **模型路径**: 在 `configs/default.yaml` 中配置正确的模型路径
3. **工作目录**: 生成的文件保存在 `work/` 目录
4. **浏览器**: 支持 Chrome、Firefox、Edge 等现代浏览器
